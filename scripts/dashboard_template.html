About

What It Does

Mines OHLCV crude data across a live Iran-Israel war timeline for repeatable conditional-probability patterns. 15-stage automated pipeline: data ingestion, regime classification, window analysis, triplet mining, statistical rigor (FDR/Bayesian), signal generation, walk-forward backtest, dashboards. Single command regenerates everything.

Statistical Rigor

Bayesian Dirichlet posteriors + 95% HDI, Benjamini-Hochberg FDR per family, hierarchical shrinkage, regime-relative magnitude tiers, walk-forward expanding-window backtest, Monte Carlo 95% CI on all metrics. Every number carries n and a LOW-CONFIDENCE flag at n<5.

Tech Stack

Python 3.12 - pandas 3.0 - numpy - scipy - scikit-learn - Chart.js - 50+ scripts - 20K+ lines - 80K+ rows across 13 source files. Single entry: python scripts/enhanced_update_all.py --signals-only
