## Evidence Extraction: Figma-to-Code Conversion & Environment Setup

### Source Scope
Single synthesized summary covering 13 sessions of a user's effort to convert exported Figma design files (TASL Canteen Bill Management Software, mobile payment flow) into frontend code, plus repeated environment setup struggles.

---

### 1. Problem, Goal, Constraints
- **Goal**: Convert Figma design exports into working frontend applications (React Native, Vite+React PWA, CRA+React PWA, React+Tailwind).
- **Core constraint**: Figma JSON is a deeply nested tree (`document → children → CANVAS → FRAME → elements`) using `absoluteBoundingBox` for positioning, `fills` for styling (SOLID color in 0–1 RGBA or IMAGE with `imageRef` hashes), and `characters` for text. No responsive layout hints; absolute coordinates only.
- **Ambiguity**: Image fills require separate Figma API calls (`imageRef` → URL); interaction states (hover, focus, disabled) not present in JSON; exact spacing/font loading/responsive behavior unspecified in component-level sessions.
- **Initial state**: `package.json` listed `figma-build`, `figma-ui`, `react-native` but no working application.

---

### 2. User Actions vs. Assistant Suggestions

**User-driven (Sessions 1, 3, 4, 9, 11, 13):**
- Attempted to run `App.js` directly with Node.js; hit `SyntaxError: Unexpected token '<'` (JSX untranspiled). No Android emulator running (`adb devices` empty).
- Accepted pivot from React Native to Vite+React PWA for faster visual iteration.
- Built `FigmaRenderer.jsx` through four versions: basic TEXT/RECTANGLE → recursive `absoluteBoundingBox` positioning → defensive defaults + RGBA conversion → image placeholder.
- Added `"type": "module"` to `package.json`; used `.cjs` for CommonJS interop; rendered only first screen to reduce complexity.
- Session 3: Set up CRA + `react-scripts`; installed `react-native-svg`; configured `manifest.json` and custom `service-worker.js`; used static JSON import; explicit `.jsx` extensions; `ReactDOM.render()` (React 17) instead of `createRoot`.
- Session 3: Systematically fixed five compilation errors: missing `start` script, CSS-in-JS Babel error, React 17 vs 18 API mismatch, ESM extension requirements, dynamic JSON import failure.
- Session 4: Diagnosed `designData.map is not a function` as nested-object vs. flat-array mismatch; removed invalid `Extracted Text Nodes:` prefix from JSON; corrected extraction path to `document.children[0].children[0].children`; rewrote recursive renderer mapping `fills→backgroundColor`, `strokes→border`, `absoluteBoundingBox→absolute positioning`.
- Session 11: Troubleshot Tailwind CLI in PowerShell (PATH, global vs. local install, `npx`); adapted `rm -rf` to `Remove-Item`; blocked by `ENOSPC` disk-space error.
- Session 13: Diagnosed Node version mismatch for `figma-build@0.0.2-0` (needed Node 18.15.0/pnpm 8.1.0, had Node 22.14.0); installed nvm-windows; distinguished PowerShell vs. CMD vs. VS Code terminal contexts; planned `D:\nvm` no-spaces path and System PATH edits; clean-slate strategy (`node_modules`, `package-lock.json`, npm cache).

**Assistant-driven / low user autonomy (Sessions 5, 7, 11 partial):**
- Session 5: User shared JSON twice and asked "check and tell if it needs fixes"; no problem decomposition, hypothesis testing, or independent investigation. Assistant identified structural issues and generated React+Tailwind code. No evidence user integrated, tested, or deployed.
- Session 7: Assistant parsed two nodes (RECTANGLE + TEXT) and proposed a pixel-faithful React+Tailwind button component. No evidence user ran, tested, or integrated it.
- Session 11: User followed step-by-step AI instructions for environment setup; final build not confirmed.

### 3. Tools, Technologies, Integrations
- **Figma**: design source; JSON export via `figma-build`/`figma-ui`; node types FRAME, RECTANGLE, TEXT, VECTOR, GROUP, INSTANCE, ELLIPSE; `absoluteBoundingBox`, `fills` (SOLID/IMAGE), `characters`, `style`, `constraints` (TOP/LEFT), `cornerRadius: 15`, `strokeAlign: "INSIDE"`, `blendMode: "PASS_THROUGH"`, `effects: []`.
- **Runtimes/bundlers**: React Native (Metro/Babel, Android emulator), Vite + React (localhost:5173), Create React App + `react-scripts` (React 17, localhost:3002), React + Tailwind CSS.
- **PWA**: `manifest.json`, custom `service-worker.js` (install/fetch/activate handlers), service-worker registration in `useEffect`.
- **Node environment**: Node 22.14.0 / npm 10.9.2 initially; targeting Node 18.15.0 / pnpm 8.1.0; nvm-windows; Windows PATH/terminal context issues; `EPERM`, `node-gyp`, `node-sass` native dependency failures.
- **Module system**: ESM (`"type": "module"`), `.cjs` interop, explicit `.jsx` extensions, static top-level JSON import.

---

### 4. Renderer Architecture (converged across Sessions 1, 3, 4)
- Recursive `renderNode` handling arbitrary nesting depth (FRAME/GROUP as containers).
- `absoluteBoundingBox` → CSS `position: absolute; left/top/width/height`.
- `fills` → CSS `backgroundColor`; Figma 0–1 RGBA → CSS 0–255 `rgba()` via `Math.round(color * 255)`.
- `strokes` → `border`.
- Node handling: TEXT (font size/family/weight/alignment), RECTANGLE/ELLIPSE/LINE (shapes), VECTOR (paths), INSTANCE (component references).
- Defensive defaults for missing `fills`, `absoluteBoundingBox`, `children`, `characters`, `style`.
- Image fills: placeholder only; `imageRef` hashes require separate Figma API image-export call (not implemented in any session).
